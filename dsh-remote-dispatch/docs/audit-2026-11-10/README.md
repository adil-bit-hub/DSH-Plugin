# 代码审计归档（2026-11-10）

这份目录是 `dsh-remote-dispatch` 在 **2026-11-10** 做的一轮代码审查与安全加固的产物。

## 重要：这是历史快照

审计针对的是当时那一版代码（9 个工具、尚无会话接力功能）。此后代码继续演进，主要变化：

| 审计时的状态 | 现在 |
| --- | --- |
| 9 个 agent 工具 | 11 个（新增 `remote_push_session` / `remote_pull`） |
| 整目录打包上传 | 只上传本会话涉及的文件 |
| 无会话接力 | 对话记录写成 `CONVERSATION.md`，由云端 agent 自行读取 |
| 无设备管理界面 | 设置页可绑定/检测/设默认/解绑 |
| — | 新增 `src/sessions.js`（多帧 zstd 解码、转录导出、文件识别） |

所以：**文件清单、行号、工具数量等细节已经过时**，不要照着这份文档核对当前代码。
它保留下来的价值在于审计结论——安全模型、威胁建模、以及当时发现并修复的缺陷类型，
这些仍然成立。

## 包含内容

## 脱敏说明

发布前对文档做过脱敏：主机 IP 换成文档保留地址（`203.0.113.x`），
凭据 id 换成占位符，用户名与本地路径替换为 `you`。
这些替换不影响审计结论。
